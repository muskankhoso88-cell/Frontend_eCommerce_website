- 🔍 Search bar with category filter

- 🗂️ Product categories
- 🛒 Product listing grid with filters
- 📄 Product detail page
- 🎨 Color & size selector
- ➕ Add to cart & Buy now buttons
- 🌍 Multi-language & currency UI
- 🔗 Footer with useful links
